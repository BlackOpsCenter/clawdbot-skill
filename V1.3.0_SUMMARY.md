# v1.3.0 Summary - Customer-Agnostic Release

## What Changed

The BlackOps Center skill is now **fully customer-agnostic** with zero hardcoded site references.

## Key Improvements

### 1. **Simplified Configuration**

**Before (v1.2.0):**
```yaml
api_token: "token"
base_url: "https://blackopscenter.com"

sites:
  - id: "abc-123"
    domain: "voicecommit.com"
    name: "VoiceCommit"
    default: true
  - id: "def-456"
    domain: "benenewton.com"
    name: "Ben Newton Personal"
```

**After (v1.3.0):**
```yaml
api_token: "token"
base_url: "https://blackopscenter.com"

# Optional default
default_domain: "yourdomain.com"
```

### 2. **Auto-Discovery Workflow**

Users no longer manually configure sites. Instead:

```bash
# 1. Add token to config.yaml
# 2. Discover sites automatically
blackops-center list-sites

# Returns all sites accessible via token:
{
  "sites": [
    {"id": "abc-123", "domain": "site1.com", "name": "Site 1"},
    {"id": "def-456", "domain": "site2.com", "name": "Site 2"}
  ]
}

# 3. Use commands with --domain flag
blackops-center list-posts --domain site1.com
```

### 3. **Generic Documentation**

All examples now use generic placeholders:
- `yourdomain.com` instead of `voicecommit.com`
- `example.com` instead of `benenewton.com`
- `anothersite.com` instead of `vitalwall.com`
- `Your Site` instead of `VoiceCommit`

### 4. **Zero Hardcoding**

No customer-specific references remain in:
- Configuration examples
- Command examples
- README documentation
- SKILL.md guide
- Quick reference

## Benefits

✅ **Ready for any customer** - Works immediately with any BlackOps Center account  
✅ **No manual site setup** - Sites auto-discovered from token permissions  
✅ **Simpler onboarding** - Just add token, run `list-sites`, done  
✅ **ClawHub ready** - Can be published without any modifications  
✅ **Open source friendly** - No private site info in examples  

## Files Changed

- `config.example.yaml` - Removed sites array, simplified to token-only
- `README.md` - Updated examples with generic domains
- `SKILL.md` - Updated setup guide and examples
- `QUICK_REFERENCE.md` - Updated all command examples
- `bin/blackops-center` - Added `DEFAULT_DOMAIN` environment variable support
- `CHANGELOG.md` - Documented v1.3.0 changes
- `CUSTOMER_AGNOSTIC.md` - New documentation on customer-agnostic design

## Migration for Existing Users

Existing users with v1.2.0 can update their `config.yaml`:

**Option 1: Keep it simple (recommended)**
```yaml
api_token: "your-token"
base_url: "https://blackopscenter.com"
```

**Option 2: Set a default**
```yaml
api_token: "your-token"
base_url: "https://blackopscenter.com"
default_domain: "yourmainsite.com"
```

The old `sites` array is ignored and no longer needed.
